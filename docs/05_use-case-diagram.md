# Диаграмма вариантов использования

## 1. Назначение документа

Документ описывает диаграмму вариантов использования информационной системы документооборота предприятия с модулем автоматизации конфигурации серверной инфраструктуры.

Диаграмма отражает основные роли пользователей, доступные им функции и границы системы. Она разработана в нотации UML.

## 2. Акторы системы

| Актор | Описание |
|---|---|
| Инициатор | Создаёт документы на проведение инфраструктурных работ и отслеживает их обработку. |
| Согласующий | Рассматривает документы и принимает решения о согласовании или отклонении. |
| Системный администратор | Управляет перечнем серверов, запускает разрешённые Ansible-сценарии и контролирует результаты выполнения. |
| Администратор системы | Управляет учётными записями пользователей и назначением ролей. |
| Аудитор | Просматривает журнал аудита и сведения, необходимые для проверки действий пользователей и выполнения работ. |

## 3. Варианты использования

Диаграмма включает десять вариантов использования, подробно описанных в документе `03-use-cases.md`.

К ним относятся авторизация, создание и согласование документов, поиск документов, управление серверами, запуск и контроль инфраструктурных работ, формирование электронного акта, просмотр журнала аудита и управление пользователями.

## 4. Связи и ограничения доступа

Связи между акторами и вариантами использования показывают, какие функции доступны каждой роли.

Доступ к документам и результатам выполнения работ ограничивается полномочиями пользователя. Запуск инфраструктурных работ допускается только для согласованных документов при соблюдении установленных условий.

Авторизация является предусловием выполнения защищённых операций. Отдельная связь `<<include>>` для авторизации не используется.
