# Информационная система документооборота предприятия

Дипломный проект на тему «Информационная системы документооборота предприятия с модулем автоматизации конфигурации серверной инфраструктуры».

## О проекте

Проект представляет собой информационную систему для организации документооборота, связанного с изменениями серверной инфраструктуры предприятия.

Система предназначена для подготовки и согласования документов на проведение инфраструктурных работ, контроля их выполнения и хранения результатов. Отдельный модуль автоматизации позволит запускать разрешённые операции на серверах на основании согласованных документов.

## Основные возможности

Планируемые функции системы:

- создание и согласование документов на изменение инфраструктуры;
- разграничение доступа на основе ролей пользователей;
- ведение перечня серверов;
- запуск разрешённых сценариев автоматизации инфраструктурных работ;
- отслеживание статуса и результатов выполнения работ;
- формирование электронных актов на основании результатов выполнения;
- ведение журнала аудита действий пользователей и операций системы.

## Технологии

Технологический стек:

- **Backend:** Python, FastAPI
- **Frontend:** Vue 3, TypeScript
- **База данных:** PostgreSQL
- **Автоматизация:** Ansible
- **Фоновые задачи:** Celery, Redis
- **Хранение файлов:** MinIO
- **Контейнеризация:** Docker Compose

Состав технологий может уточняться в ходе разработки.
